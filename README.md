# PinkJack

Proyecto desarrollado en Java que implementa una versión del clásico juego de cartas Blackjack (21).

El jugador se enfrenta a un crupier, realiza apuestas y busca conseguir una puntuación cercana a 21 sin superarla.

## Tecnologías
- Java
- Maven

## Características
- Mazo de 52 cartas.
- Sistema de apuestas.
- Cálculo de puntuaciones.
- Turnos del jugador y crupier.
- Determinación del ganador.
